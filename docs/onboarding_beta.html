CloudGuard JP オンボーディングガイド

AWSセキュリティスキャンCLI — 5分でセットアップ完了

STEP 1

動作環境の確認

CloudGuard JP は Python 3.9 以上が必要です。以下のコマンドで確認してください。

python --version
# Python 3.9.x 以上であればOK
Python が入っていない場合は python.org からインストールしてください。
STEP 2

リポジトリのクローンとインストール

git clone https://github.com/yorosiku008/cloudguard-cli.git
cd cloudguard-cli
pip install -r requirements.txt

インストールされる主なライブラリ:

  • boto3 — AWS SDK
  • rich — ターミナル出力の整形
STEP 3

まずデモモードで動作確認（AWS不要）

AWS アカウントがなくてもサンプルデータでスキャン結果を確認できます。

python main.py --demo
CRITICAL 2件・HIGH 4件・MEDIUM 3件・LOW 1件 のサンプル結果が表示されます。

重要度でフィルター表示

python main.py --demo --severity CRITICAL HIGH

Markdown レポートの出力

python main.py --demo --output-md
# カレントディレクトリに cloudguard_report_YYYYMMDD.md が生成されます
STEP 4

AWS 認証の設定（実環境スキャン）

実際の AWS アカウントをスキャンする場合は AWS CLI の認証設定が必要です。

方法A: AWS CLI で設定（推奨）

aws configure
# AWS Access Key ID: <your-key>
# AWS Secret Access Key: <your-secret>
# Default region name: ap-northeast-1
# Default output format: json

方法B: 名前付きプロファイル

aws configure --profile mycompany
python main.py --profile mycompany
本番アカウントでは ReadOnly 権限の IAM ユーザーを使うことを強く推奨します。
STEP 5

スキャンの実行

全サービスをスキャン

python main.py --profile default

スキャン対象サービスを絞る

python main.py --services s3 iam
python main.py --services ec2
python main.py --services cloudtrail

CRITICAL のみ表示して MD レポート出力

python main.py --severity CRITICAL --output-md
オプション説明デフォルト
--profileAWS プロファイル名default
--servicesスキャン対象（s3 iam ec2 cloudtrail）全サービス
--severity表示する重要度フィルター全重要度
--output-mdMarkdown レポートを出力off
--demoAWS 不要のデモモードoff
STEP 6

検出ルールと重要度

CRITICAL
即時対応が必要。アカウント乗っ取りリスク
HIGH
早急に対応。データ漏洩・不正アクセスリスク
MEDIUM
計画的に対応。セキュリティベストプラクティス
LOW
推奨対応。可視性・監査ログの強化
ルールIDサービス重要度説明
IAM_ROOT_ACCESS_KEYIAMCRITICALrootアカウントにアクセスキーが存在
IAM_ROOT_MFA_DISABLEDIAMCRITICALrootアカウントのMFAが無効
S3_PUBLIC_ACLS3HIGHS3バケットが公開ACL設定
S3_PUBLIC_BLOCK_DISABLEDS3HIGHパブリックアクセスブロックが無効
EC2_SG_SSH_OPENEC2HIGHSSH(22)が全インターネットに公開
EC2_SG_RDP_OPENEC2HIGHRDP(3389)が全インターネットに公開
CLOUDTRAIL_NOT_ENABLEDCloudTrailHIGHCloudTrailが未設定
S3_VERSIONING_DISABLEDS3MEDIUMバージョニングが無効
S3_ENCRYPTION_DISABLEDS3MEDIUMデフォルト暗号化が無効
IAM_PASSWORD_POLICY_MISSINGIAMMEDIUMパスワードポリシーが未設定
CLOUDTRAIL_NOT_MULTIREGIONCloudTrailMEDIUMシングルリージョン設定
S3_LOGGING_DISABLEDS3LOWアクセスログが無効
